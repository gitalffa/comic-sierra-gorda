## 📋 Descripción

**Viaje a la Sierra Gorda** es un cómic web narrativo que documenta de forma humorística e ilustrada la rodada en motocicleta que el grupo _Amigos de la Carretera_ realizó a la Sierra Gorda de Querétaro. El proyecto presenta a cada integrante con su ficha técnica personal (moto, frase y anécdota), y narra el viaje día a día con viñetas, imágenes y texto estilo cómic.

Es un proyecto **100% personal**, desarrollado con HTML y CSS puros, sin frameworks ni librerías externas. El estilo usa la tipografía **Comic Neue** para darle un look auténtico de historieta.

---

## ✨ Contenido del cómic

- **Prólogo** — Presentación épica (y humorística) del grupo y el viaje
- **Fichas técnicas** — 17 personajes con foto ilustrada, moto, frase y anécdota personal
- **Día 1 - "El llamado de la carretera"** — Salida desde Bonaterra, desayuno en Fonda La Lupita, parada en Lagos de Moreno y travesía con viento y desvíos legendarios
- **Día 2 - Llegando a la Sierra** _(en construcción)_
- **Día 3 - El regreso** _(en construcción)_

## 🛠 Tecnologías

| Tecnología                | Uso                                                    |
| ------------------------- | ------------------------------------------------------ |
| HTML5 semántico           | Estructura narrativa del cómic                         |
| CSS3                      | Layout responsivo, estilos de viñetas y tarjetas       |
| CSS modular (4 archivos)  | `base.css`, `layout.css`, `components.css`, `day1.css` |
| Google Fonts — Comic Neue | Tipografía estilo historieta                           |
| JavaScript vanilla        | Menú hamburguesa responsive                            |
| GitHub Pages              | Publicación del proyecto                               |

## 🗂 Estructura del proyecto

```
comic-sierra-gorda/
├── index.html          # Estructura completa del cómic
├── css/
│   ├── base.css        # Reset y variables globales
│   ├── layout.css      # Grid y estructura de página
│   ├── components.css  # Tarjetas, viñetas y nav
│   └── day1.css        # Estilos específicos del Día 1
├── images/             # Ilustraciones y fotos del viaje
├── vendor/             # Recursos externos
└── favicon.ico
```

## 🚀 Cómo ver localmente

```bash
# Clona el repositorio
git clone https://github.com/gitalffa/comic-sierra-gorda.git

# Entra al directorio
cd comic-sierra-gorda

# Abre index.html en tu navegador
# (o usa Live Server en VS Code)
```

No requiere instalación de dependencias.

## 📐 Conceptos aplicados

- **CSS modular** — Separación de estilos en archivos por responsabilidad
- **CSS Grid y Flexbox** — Layout de viñetas y fichas de personajes
- **Diseño responsive** — Menú hamburguesa y layout adaptable
- **HTML5 semántico** — Uso de `<section>`, `<nav>`, `<header>` correctamente
- **BEM** — Nomenclatura de clases CSS organizada
